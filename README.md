## 🚀 설치 방법

### Foundry VTT

1. 모듈 추가 → `manifest.json` URL 입력
2. *PF2e‑KR* 모듈 활성화 후 게임 재시작
3. **설정 > 언어(Language)** 를 `한국어 (PF2e‑KR)`로 선택

### 기타 모드(Pathbuilder, Animal Companion 등)

*별도 패치 스크립트를 준비 중입니다.*
