# PF2e-KR

Foundry VTT용 **Pathfinder 2e 한국어 번역 모듈** — 컴펜디움(주문·피트·장비·몬스터·저널 …)과 UI를 한국어로.
*Korean translation of the Pathfinder 2e system for Foundry VTT.*

- 컴펜디움 이름은 `화염 광선(Fire Ray)`처럼 영문을 함께 적어 검색과 대조가 쉽습니다(설정으로 끌 수 있음).
- PF2e 시스템 UI 문자열 번역.
- 이미 월드에 들어간 영문 아이템·효과를 한글판으로 바꾸는 GM 도구.
